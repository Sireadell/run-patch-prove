      Step 3 of 3 · Prove

      Check the proof yourself

      Each run ends in a report. The report carries a seal, a fingerprint made from everything written in it. Your browser works out the fingerprint again right now and compares. Change anything in the box, even one letter, and the check fails.

      You can also click in the box and type anything yourself. Spaces and line breaks do not count. Letters and numbers do.

      How the check works: take the report without its seal, put the keys in alphabetical order, run SHA-256 (your browser's own tool), and compare the result with the seal. The repo has the same check as verify.py so you can run it offline.

      What this is not

      • The seal does not say who made the report. It is a fingerprint. It proves the report was not edited after it was sealed. A signature from a private key would be the next step.
      • The fix was written ahead of time. It is a fixed version of the agent, not an AI writing code live inside the sandbox.
      • The agent is a small demo agent, not a production one. It exists so the attacks and the fixes are easy to read.
      • The attacks are harmless. They only echo text. Nothing is deleted and nothing leaves the sandbox.
